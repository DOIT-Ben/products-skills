# Products Investigate

Use this before changing code when behavior is surprising, broken, or regressed.

## Output

- Reproduction status or narrowed trigger.
- Evidence inspected: logs, errors, tests, browser state, data, or relevant code.
- Root cause, stated as specifically as the evidence allows.
- Minimal fix path.
- Validation command or check that will prove the fix.
